## Overview

This dataset consists of raw 64-channel EEG, electrocardiography (ECG), photoplethysmography (PPG), eye-tracking/pupillometry, and behavioral data recorded from 124 healthy young adults during two experimental conditions: resting state and a verbal working memory digit-span task with serial recall.

## Resting-state recording

During the resting-state session, participants alternated between four 1-minute blocks of eyes-closed and eyes-open rest. This was followed by 3 minutes and 52 seconds of passive cartoon watching ("The Man Who Was Afraid of Falling", 2011). 

## Verbal working memory task

In the verbal working memory task - adaptive digit span, participants were presented visually with sequences of digits and recalled them in serial order. Sequence length was adaptive and depended on each participant's performance. Trials were grouped into blocks of 10 trials. If a participant correctly recalled 7 or more trials in a block, the sequence length increased in the next block. If fewer than 7 trials were recalled correctly, the sequence length decreased in the next block.

## Apparatus

Several modalities were recorded simultaneously during the resting-state and working memory tasks. EEG was recorded using a 64-channel EEG system (Brain Products). ECG, PPG were recorded from AUX channels of the Brain Products amplifier. Eye-tracking/pupillometry was recorded with Pupil Labs Core wearable eye-tracker. Behavioral responses were collected during the digit-span task - participants typed their responses using numpad. Correctness of each response - each individual digit recall in the sequence - is stored in the event triggers.

## Task organization

Participants completed a resting-state recording followed by the verbal working memory task. The resting-state recording included alternating eyes-closed and eyes-open blocks, followed by passive video watching. The working memory task consisted of adaptive digit-span trials with serial recall.
